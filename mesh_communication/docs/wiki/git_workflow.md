# Git Workflow

+ Development:
  + There are one branch for each team, ours being **t2_development**;
  + Noone should push directly to **t2_development** unless it's to update doc files;
  + Every created branch must have the prefix "t2_";
+ Merges to **t2_development** must be pull requests and the person that requests cannot accept own pull requests;
+ Project owner should accept every pull request;
